# CppMe Chapter 3

A C++ learning project for Chapter 3 of **C++ Programming Made Easy**.

## Overview

This repository contains a Visual Studio C++ project with a simple introductory program that prints `Hello World!` to the console.

## Getting Started

1. Clone this repository.
2. Open `CppMe_chapter3.slnx` or `CppMe_chapter3.vcxproj` in Visual Studio.
3. Build and run the project.

You can also run without debugging using **Ctrl+F5** in Visual Studio.

## Source

- [`CppMe_chapter3.cpp`](CppMe_chapter3.cpp) — program entry point and sample output.

## Requirements

- Visual Studio with C++ development tools installed.
